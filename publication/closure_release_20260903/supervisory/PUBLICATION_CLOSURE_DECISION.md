## Publication routes

### Route A - validated domain

A frozen transport-calibrated surrogate preserves transport, squeezing sign, component ranking, and time profile on untouched exact/Krylov cases.

First target: **Physical Review A** or **Physical Review Research**.

### Route B - stable failure boundary

The surrogate fails outside a predictable domain and the boundary outperforms hole-count-only, connectivity-only, and static-dilution baselines.

First target: **Physical Review A** or **Physical Review Research** if broad and physically informative.
Fallback: **APS Open Science** or **Journal of Physics B** for a rigorous narrower or negative result.

### Route C - no useful domain or boundary

Stop the physics line. Pursue a software/metapaper only after a clean public release, an OSI licence, documentation, a worked example, a DOI, and an external installation test. JOSS is not an immediate route because the current repository lacks the required public development and impact evidence.

## Absolute claim boundary

Allowed now:

- The A5 G0 object reconstructs on two physically distinct host-evidence legs.
- Both supplied hosts passed 402 full and 169 targeted tests.
- A selected 3x3x3 moving-occupancy surrogate shows a replicated negative static-only minus mobile-plus-spin-density contrast.
- One strict G1-only attempt is authorised by the attached receipt.

Forbidden now:

- Exact lithium mobile-hole dynamics.
- A causal mobile-hole mechanism.
- A universal no-go boundary.
