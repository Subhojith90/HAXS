# HAXS code-and-data reproducibility release v1.0.0

This is the immutable software and data release supporting the manuscript **“A
reproducible fixed-time spin-squeezing-parameter contrast in a stochastic
moving-occupancy XXZ surrogate.”**

## Included

- simulation, analysis, verification, and packaging source code;
- frozen configurations, deterministic plans, dependency locks, and tests;
- complete primary and frozen-confirmation source tables used in the paper;
- deterministic figure-generation script and publication figures;
- exact-diagonalization/DTWA small-system comparison;
- two-host G0 reproducibility records and terminal G1 evidence;
- publication-closure report, claim boundary, and SHA-256 manifests;
- deterministic figure-generation code, final plots, and their source tables.

The unpublished manuscript and its circulation deliverables are intentionally
excluded from this software/data release.

## Scientific boundary

The supported result is a replicated fixed-time contrast within the selected
3x3x3 stochastic moving-occupancy XXZ surrogate. This release does not claim a
microscopic mobile-hole mechanism, component-level causality, finite-size
scaling, universality, an experimental prediction, or a scientific result from
the later G1 workflow that terminated before producing scientific files.
