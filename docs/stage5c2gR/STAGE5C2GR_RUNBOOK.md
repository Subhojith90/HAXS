# Stage 5C.2G-R runbook

Stage 5C.2G-R is a bounded protocol repair and calibration re-lock. It does not authorize untouched validation, fixed-hole production, Stage 5C3 production, Stage 5D, manuscript-result claims, or public release.

## Scientific scope

The exact comparator transports spin-carrying hard-core bosons through a constrained Hilbert space. It is not a fermionic lithium-6 comparator. The allowed claim is limited to a controlled hard-core-boson benchmark of a stochastic occupancy-mask surrogate.

Every scientific contrast uses common random numbers. Occupancy, hole path, DTWA phase batch, exact initial state, and block identifiers are derived from split/case/replicate indices and never from label names.

## G0 - artifact identity and protocol re-lock

Run full and targeted tests, planned invariants, candidate generation, deterministic protocol packaging, and the current-stage fresh-unzip gate. The lock covers every local Python source and script, every YAML configuration, all tests, the Stage 5C.2G-R runbooks, and environment metadata. Predecessor objects follow the content-addressed `HAXS_CUSTODY_ROOT` contract.

The runtime never trusts `LOCKED.json` as authority. It reconstructs current source and custody hashes, rebuilds the canonical candidate payload, recomputes the candidate SHA-256, and requires the external receipt to contain that value.

The rejected Stage 5C.2G candidate `e9a9740caac19b51a7a1da0b0f404c804d1a45d0eff45fbc602aeeee2db1c396` must never be finalized or executed.

## G1 - paired calibration invariants

After the new candidate is externally timestamped and finalized, run only `run_stage5c2gR_calibration_invariants.py`. Static and zero-coupling labels reuse identical physical random units. Every exact and surrogate curve must agree within `1e-10 dB`. Failure writes only `FAILED.json`, exits nonzero, and blocks transport calibration and all later stages.

## G2 - transport mobility mapping

Only after G1 passes, fit the stochastic mobility parameter on calibration-only hole density, mean-squared displacement, return probability, and configuration-distribution distance. Squeezing and validation cases are forbidden tuning inputs. The mapping reports a bootstrap interval and time-window sensitivity. Failure creates no mapping lock.

## Calibration-only benchmark

Only after G2 passes, run the replicated calibration benchmark. It uses two occupancy units, four paths per occupancy, four phase batches per path, and 1024 DTWA trajectories per phase batch. The tolerance lock is written only if static-profile, exact-accounting, all-attempts-completed, paired-zero-limit, and transport gates pass. A failed calibration cannot create a usable lock.

Stop after calibration and submit the calibration package for supervisory review. Untouched validation must remain untouched.

## Conditional later stages

Untouched validation independently checks the protocol, G1 lock, transport mapping, and passed tolerance lock before creating its output directory. It reports per-occupancy/path/phase metrics, transport discrepancies, sign stability, local-window signs, and component ranking with a predeclared `0.05 dB` near-tie rule.

Fixed-hole production additionally requires a written supervisor approval containing the current candidate SHA and passed validity-gate SHA. Its candidate-specific output roots and per-chunk manifests reject stale files, mixed candidates/configurations, incomplete attempt ledgers, duplicate IDs, modified files, and nondeterministic merges.

The fixed-hole confirmatory estimand uses a `0.15 dB` smallest effect of scientific interest and a joint bootstrap maximum-deviation interval across counts and nearby times. Topology remains explicitly exploratory.
